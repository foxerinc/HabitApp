# Habit Tracker App - **Build Better Habits. One Day at a Time.**

**Habit Tracker App** is a productivity-focused Android application inspired by the proven Pomodoro Technique. Created as part of the **Dicoding Dev Certification for Android (DCA) Preparation Course** It helps users stay committed to their personal growth goals by combining **habit tracking** with **timed focus sessions**—enabling deep work, habit consistency, and sustainable daily routines.
this app guides users to:
- Log their positive habits
- Track their focus time using a built-in countdown timer
- Get random suggestions when overwhelmed
- Stay motivated with deadline-based notifications

**[Watch Demo Video](https://drive.google.com/file/d/1FoFMJ3zDFspFpn5SLYIVXvXRGkPYzCL-/view?usp=drive_link)**

## Features
- View habit list sorted by creation date
- Add new habit with name, description, and focus duration
- View habit details
- Start countdown timer for a selected habit
- Pick a random habit when unsure which to do next
- Settings screen for managing app preferences
- Notifications for reminding habit sessions
